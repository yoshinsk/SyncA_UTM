PPPoE 接続作成
PPPoE は WAN 側 ISP 接続用です。アクティブ化すると現在の WAN 経路が切り替わる可能性があります。 コンソールで復旧できる状態で実行してください。
フレッツ系は 1454、その他 ISP は 1492 が一般的。
MSS clamp: PPPoE 経由の TCP 接続で大きいパケットが silently drop されるのを防ぐため、firewalld direct rule で TCP SYN の MSS を path MTU にクランプします。常に ON 推奨。
