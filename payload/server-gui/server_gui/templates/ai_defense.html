AI 防御

現在公開しているポートへの不審なアクセス候補について、Jev が不正の可能性を否定できない場合は安全側で遮断します。重要な接続元は遮断一覧を定期的に確認し、必要に応じて手動で解除してください。

Jev API キーの取得
  1. Typesafe AI Console にサインインします。
  2. ダッシュボードで API キーを発行し、作成直後に安全な場所へ控えます。
  3. この画面に貼り付けて有効化し、設定を保存します。

API キーが未設定の場合、この機能は確認も遮断も行いません。キーは装置内の /etc/server-gui/ai_defense.json に権限 0600 で保存され、画面には再表示しません。

Jev に渡す情報

候補を source-001 のような匿名 ID に置き換え、イベント種別の件数と現在公開している対象ポートだけを送ります。

IP アドレス、API キー、元のログ行、利用者名、要求パス、認証情報は Jev に送信しません。

遮断の条件

遮断対象は、現在公開しているポートへの認証失敗、探索的な要求、または繰り返しの記録がある候補に限ります。Jev が benign と判定し、確信度が 0.85 以上、悪性確率が 0 の場合だけ遮断しません。

malicious、insufficient、低い確信度、または悪性確率が 0 より大きい結果は遮断します。遮断には専用 IP セットを使い、firewalld の再読込は行いません。drop ゾーンの対象が DROP であることを確認できない場合は遮断しません。

AI 防御による遮断一覧 解除すると、現在の設定と再起動後の設定の両方から削除します。
