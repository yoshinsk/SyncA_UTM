計測項目の説明
下り / 上り速度
Cloudflare の固定測定先へ実際に転送したデータ量から求める実効速度です。契約上の最大速度ではありません。
平均 RTT
小さなパケットが往復する平均時間です。Web 会議や VPN など、応答性が必要な通信の目安になります。
ばらつき
RTT の揺れを示す mdev です。値が大きい場合は、通信の応答が不安定な可能性があります。
パケット損失
送信した ping に対して応答がなかった割合です。損失が続く場合は回線や経路の状態を確認してください。
リンクカウンター
WAN インターフェースが報告するエラーと破棄の累計値です。増加傾向は物理リンクや上位機器の確認材料になります。
