手書き設定 (管理対象外)

/etc/nginx/conf.d/ 配下で vhost-*.conf 以外のファイルは GUI 管理外です。 手で書いた既存設定はそのまま動作します。GUI 管理に移行する場合は同等の vhost を新規作成して旧ファイルを手動削除してください。

    バックエンド追加
    英数字 + _ -。先頭はアルファベット。
    Vhost 追加
    待受 IP を空欄にすると全 IP で待ち受けます。複数の公開 IP を使い分ける場合は対象のIPv4を指定してください。
    SSL 設定
    証明書は 証明書タブ で管理。新規取得は次の Sprint で対応予定。
    WAF (Web Application Firewall)
    nginx の limit_req / allow/deny / map / geo を組み合わせて実装。ModSecurity を有効にすると OWASP CRS による SQLi/XSS 検査も追加できます (別途インストール必要)。
    レート制限 / IP / メソッド
    limit_req_zone を生成し IP 別にレート制限。
    バーストを許容する数。これを超えると 503 を返す。
    指定した CIDR のみ許可。他は全拒否。
    指定 CIDR を拒否。許可リストより優先。
    少なくとも 1 つチェックすると、それ以外のメソッドは 403 を返す。

    選択したカテゴリの既知パターン (sqlmap / nikto / 等) を map で 403 化。
    攻撃パターン検出 (URL/クエリ)

    <script> / on*= / javascript: 等
